_For each race, lap, driver and other car pair, assemble timing/position indicators that show whether driver A is classified as 'behind' driver B on a given lap, including lap timestamps/position/sector gaps. Include pit stop and retirement markers (if available) for the involved drivers on each lap so lap-level context is present._

```sql
SELECT
  lp1.race_id AS race_id,
  lp1.lap AS lap,
  lp1.driver_id AS subject_driver_id,
  lp2.driver_id AS other_driver_id,
  CASE
    WHEN lp1.position IS NULL OR lp2.position IS NULL THEN NULL
    WHEN lp1.position > lp2.position THEN 1
    WHEN lp1.position = lp2.position THEN 0
    ELSE 0
  END AS is_behind,
  lp1.position AS position,
  -- time_gap_to_other: computed from lap_times.milliseconds if available for both drivers on this lap
  (lt2.milliseconds - lt1.milliseconds) AS time_gap_to_other,
  -- pit_on_lap_flag: 1 if either subject or other has a pit stop recorded on this lap for same race
  CASE WHEN ps1.stop IS NOT NULL OR ps2.stop IS NOT NULL THEN 1 ELSE 0 END AS pit_on_lap_flag,
  -- retired_on_lap_flag: 1 if either subject or other has a retirement record for this race and lap
  CASE WHEN r1.lap IS NOT NULL OR r2.lap IS NOT NULL THEN 1 ELSE 0 END AS retired_on_lap_flag
FROM
  lap_positions lp1
JOIN
  lap_positions lp2
  ON lp1.race_id = lp2.race_id
  AND lp1.lap = lp2.lap
  AND lp1.driver_id != lp2.driver_id
LEFT JOIN
  lap_times lt1
  ON lt1.race_id = lp1.race_id AND lt1.driver_id = lp1.driver_id AND lt1.lap = lp1.lap
LEFT JOIN
  lap_times lt2
  ON lt2.race_id = lp2.race_id AND lt2.driver_id = lp2.driver_id AND lt2.lap = lp2.lap
LEFT JOIN
  pit_stops ps1
  ON ps1.race_id = lp1.race_id AND ps1.driver_id = lp1.driver_id AND ps1.lap = lp1.lap
LEFT JOIN
  pit_stops ps2
  ON ps2.race_id = lp2.race_id AND ps2.driver_id = lp2.driver_id AND ps2.lap = lp2.lap
LEFT JOIN
  retirements r1
  ON r1.race_id = lp1.race_id AND r1.driver_id = lp1.driver_id AND r1.lap = lp1.lap
LEFT JOIN
  retirements r2
  ON r2.race_id = lp2.race_id AND r2.driver_id = lp2.driver_id AND r2.lap = lp2.lap
```

_Using lap_position_pairs, compute transitions between lap L-1 and lap L for the same race and driver-other pair to detect changes from not-behind on L-1 to behind on L (only compare consecutive laps. Handle lap=1 by comparing to starting order/pre-start representation if present). Carry through pit/retirement flags for lap L-1 and L to enable classification._

```sql
SELECT
  p_curr.race_id AS race_id,
  p_curr.lap AS lap,
  p_curr.subject_driver_id AS subject_driver_id,
  p_curr.other_driver_id AS other_driver_id,
  -- became_behind_flag: was NOT behind on L-1 but IS behind on L
  CASE
    WHEN COALESCE(p_prev.is_behind, 0) = 0 AND COALESCE(p_curr.is_behind, 0) = 1 THEN 1
    ELSE 0
  END AS became_behind_flag,
  -- pit/retirement flags carried for lap L and L-1
  COALESCE(p_curr.pit_on_lap_flag, 0) AS pit_on_lap_L_flag,
  COALESCE(p_prev.pit_on_lap_flag, 0) AS pit_on_lap_Lminus1_flag,
  COALESCE(p_curr.retired_on_lap_flag, 0) AS retired_on_lap_L_flag,
  -- time gaps for L and L-1
  p_curr.time_gap_to_other AS time_gap_L,
  p_prev.time_gap_to_other AS time_gap_Lminus1
FROM
  lap_position_pairs AS p_curr
LEFT JOIN
  lap_position_pairs AS p_prev
ON
  p_curr.race_id = p_prev.race_id
  AND p_curr.subject_driver_id = p_prev.subject_driver_id
  AND p_curr.other_driver_id = p_prev.other_driver_id
  AND p_curr.lap = p_prev.lap + 1
```

_Filter consecutive_lap_transitions to only rows where became_behind_flag is true and the race is in races_with_pit_data. Classify each event per the Overtake Label rules into 'R','P', or other/implicit labels (apply precedence: R over P if both true) and produce counts of events per overtake_type across all included races._

```sql
SELECT
  overtake_type,
  COUNT(*) AS overtake_count
FROM (
  SELECT
    clt.race_id,
    clt.lap,
    clt.subject_driver_id,
    clt.other_driver_id,
    -- Determine labels per rules: R if pit_on_lap_L_flag OR pit_on_lap_Lminus1_flag is true,
    -- P if time_gap_L IS NOT NULL AND time_gap_L <= 2.0 (seconds) and not R,
    -- else 'O' for other/implicit
    CASE
      WHEN (clt.pit_on_lap_L_flag = 1 OR clt.pit_on_lap_Lminus1_flag = 1) THEN 'R'
      WHEN (clt.time_gap_L IS NOT NULL AND CAST(clt.time_gap_L AS REAL) <= 2.0) THEN 'P'
      ELSE 'O'
    END AS overtake_type
  FROM consecutive_lap_transitions clt
  JOIN races_with_pit_data rpd ON rpd.race_id = clt.race_id
  WHERE clt.became_behind_flag = 1
) t
GROUP BY overtake_type
```

_Classify each overtake event into exactly one category using the external rules: label as 'retirement' if overtaken driver retired on same lap. Else 'pit' if event occurred during pit entry on same lap or is a pit exit consistent with a recent pit stop. Else 'start_related' if marked as start-related. Else 'on_track' for standard passes. Exclude events that lack sufficient info to assign a category._

```sql
SELECT
  oer.event_id AS event_id,
  oer.race_id AS race_id,
  oer.lap AS lap,
  oer.overtaker_id AS overtaker_id,
  oer.overtaken_id AS overtaken_id,
  CASE
    WHEN oer.retirement_flag = 1
         OR (dre.driver_id IS NOT NULL AND dre.retirement_lap = oer.lap)
      THEN 'retirement'
    WHEN oer.pit_entry_flag = 1
         OR (oer.pit_exit_flag = 1 AND oer.recent_pit_stop_indicator = 1)
      THEN 'pit'
    WHEN oer.start_related_flag = 1
      THEN 'start_related'
    WHEN oer.retirement_flag IS NULL
         AND oer.pit_entry_flag IS NULL
         AND oer.pit_exit_flag IS NULL
         AND oer.start_related_flag IS NULL
      THEN NULL
    ELSE 'on_track'
  END AS category
FROM overtake_events_raw oer
LEFT JOIN driver_retirement_events dre
  ON dre.race_id = oer.race_id
  AND dre.driver_id = oer.overtaken_id
  AND dre.retirement_lap = oer.lap
```

_For each year, choose the single top driver (highest driver_points, ties broken by lexicographically smallest full name) and the single top constructor (highest constructor_points, ties broken by lexicographically smallest constructor name). Produce one row per year combining year, driver id, driver points, constructor id, and constructor points._

```sql

  dyp.year AS year,
  dyp.driver_id AS driver_id,
  dyp.driver_points AS driver_points,
  cyp.constructor_id AS constructor_id,
  cyp.constructor_points AS constructor_points
FROM
  (
    -- pick top driver per year: highest points, tie-breaker smallest driver_id_name via drivers_ext.full_name if available
    SELECT year, driver_id, driver_points
    FROM (
      SELECT
        year,
        driver_id,
        driver_points,
        ROW_NUMBER() OVER (
          PARTITION BY year
          ORDER BY driver_points DESC,
                   (SELECT full_name FROM drivers_ext de WHERE de.driver_id = dy.driver_id) ASC,
                   driver_id ASC
        ) AS rn
      FROM driver_year_points dy
    ) WHERE rn = 1
  ) dyp
JOIN
  (
    -- pick top constructor per year: highest points, tie-breaker smallest constructor name via constructors_ext.name if available
    SELECT year, constructor_id, constructor_points
    FROM (
      SELECT
        year,
        constructor_id,
        constructor_points,
        ROW_NUMBER() OVER (
```

_All recorded position-change events that occur during race laps (exclude pre-race and post-race events). Keep full event metadata including race, lap, timing, subject driver, other driver (if applicable), position_before, position_after, event_cause flags (pit_entry, pit_exit, retirement, start_lap_flag), and any indicators whether the change was recorded as between two specific drivers._

```sql
SELECT
  -- generate a unique event id per recorded change: concat race, lap, driver, and rowid
  (race_id || '-' || lap || '-' || driver_id || '-' || rowid) AS event_id,
  race_id AS race_id,
  lap AS lap_number,
  driver_id AS driver_id,
  NULL AS other_driver_id,
  -- derive position_before and position_after from lap_positions by comparing this lap to previous lap where available
  COALESCE(
    (SELECT position FROM lap_positions lp_before
     WHERE lp_before.race_id = lp_current.race_id
       AND lp_before.driver_id = lp_current.driver_id
       AND lp_before.lap = lp_current.lap - 1
     LIMIT 1),
    (SELECT position FROM lap_positions lp_start
     WHERE lp_start.race_id = lp_current.race_id
       AND lp_start.driver_id = lp_current.driver_id
       AND lp_start.lap = lp_current.lap
     LIMIT 1)
  ) AS position_before,
  (SELECT position FROM lap_positions lp_after
     WHERE lp_after.race_id = lp_current.race_id
       AND lp_after.driver_id = lp_current.driver_id
       AND lp_after.lap = lp_current.lap
     LIMIT 1) AS position_after,
  -- flags derived from pit_stops and retirements and lap number being 1 (start lap)
  CASE WHEN EXISTS (
    SELECT 1 FROM pit_stops ps
    WHERE ps.race_id = lp_current.race_id
      AND ps.driver_id = lp_current.driver_id
      AND ps.lap = lp_current.lap
  ) THEN 1 ELSE 0 END AS pit_entry_flag,
  -- pit_exit_flag is not directly present; infer if same driver had a pit stop on this lap and duration present => treat as exit also true

      AND ps2.driver_id = lp_current.driver_id
      AND ps2.lap = lp_current.lap
      AND ps2.milliseconds IS NOT NULL

    SELECT 1 FROM retirements r
    WHERE r.race_id = lp_current.race_id
      AND r.driver_id = lp_current.driver_id
      AND CAST(r.lap AS INTEGER) = lp_current.lap
  ) THEN 1 ELSE 0 END AS retirement_flag,
  CASE WHEN lp_current.lap = 1 THEN 1 ELSE 0 END AS start_lap_flag,
  -- attempt to use lap_times.time as event timestamp when available, else fall back to pit_stops.time, else NULL
  COALESCE(
    (SELECT time FROM lap_times lt
     WHERE lt.race_id = lp_current.race_id
       AND lt.driver_id = lp_current.driver_id
       AND lt.lap = lp_current.lap
     LIMIT 1),
    (SELECT time FROM pit_stops ps3
     WHERE ps3.race_id = lp_current.race_id
       AND ps3.driver_id = lp_current.driver_id
       AND ps3.lap = lp_current.lap
     LIMIT 1),
    NULL
  ) AS event_timestamp
FROM
  lap_positions lp_current
WHERE
  -- intrinsic filter: must occur during race laps (exclude pre/post-race). We assume lap >= 1 indicates in-race.
  lp_current.lap >= 1
```

_Subset of position-change events from race_position_changes_raw that represent on-track positional changes: exclude any events flagged as pit_entry, pit_exit, retirement, or start-of-race lap (lap 1). Also keep only events that reflect a one-position exchange between two drivers on consecutive lap records (i.e., attributable to an on-track pass)._

```sql
SELECT
  race_id,
  lap_number,
  event_id,
  driver_id,
  other_driver_id,
  position_before,
  position_after,
  event_timestamp,
  CASE
    WHEN position_after < position_before THEN 'gain'
    WHEN position_after > position_before THEN 'loss'
    ELSE 'no_change'
  END AS position_change_direction
FROM race_position_changes_raw
WHERE
  -- exclude pit related events
  COALESCE(pit_entry_flag, 0) = 0
  AND COALESCE(pit_exit_flag, 0) = 0
  -- exclude retirements
  AND COALESCE(retirement_flag, 0) = 0
  -- exclude start-of-race lap (lap 1)
  AND COALESCE(start_lap_flag, 0) = 0
  AND COALESCE(lap_number, 0) <> 1
  -- only one-position exchanges between two drivers on consecutive lap records:
  -- ensure the absolute change is exactly 1 and there is an other_driver involved
  AND other_driver_id IS NOT NULL
  AND ABS(position_after - position_before) = 1
```

_Normalize each on-track position-change event into two perspective flags: for the subject driver, whether they 'overtook' another driver (gained a position) or were 'overtaken' (lost a position). Keep event-level indicator columns suitable for aggregation._

```sql
SELECT
  rpc.event_id AS event_id,
  rpc.race_id AS race_id,
  rpc.lap_number AS lap_number,
  rpc.driver_id AS driver_id,
  rpc.other_driver_id AS other_driver_id,
  CASE
    WHEN rpc.position_after > rpc.position_before THEN 1
    ELSE 0
  END AS was_overtaken_flag,
  CASE
    WHEN rpc.position_after < rpc.position_before THEN 1
    ELSE 0
  END AS overtook_flag
FROM race_position_changes_ontrack AS rpc
```

_Aggregate the normalized event flags to compute, for each driver, total counts of times they were overtaken on track and times they overtook others across all races/laps._

```sql
SELECT
  per_event_overtake_flags.driver_id AS driver_id,
  SUM(CASE WHEN per_event_overtake_flags.was_overtaken_flag = 1 THEN 1 ELSE 0 END) AS total_was_overtaken,
```
